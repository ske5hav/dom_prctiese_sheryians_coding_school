# JavaScript DOM Practice 🚀

Today, I practiced JavaScript DOM manipulation at Sheryians Coding School. The main goal was to apply the concepts I have been learning and understand how JavaScript interacts with HTML elements to make a webpage interactive.

Aaj maine sirf theory revise nahi ki, balki DOM methods ka use karke practical implementation par kaam kiya. Maine form handling, dynamic user cards, user data management aur CSS animations ko ek practice project mein combine karne ki koshish ki.

## 💻 What I Practiced Today

### 1. DOM Manipulation
- Used `querySelector()` to select HTML elements.
- Practiced accessing and updating elements through JavaScript.
- Worked with `innerHTML` to update webpage content dynamically.
- Used `createElement()` to create HTML elements through JavaScript.

### 2. Form Handling and Validation
- Practiced getting values from input fields.
- Worked with form submission using `addEventListener()`.
- Used `preventDefault()` to prevent the default form submission behavior.
- Practiced checking empty inputs and handling user-entered data.

### 3. Dynamic User Cards
- Practiced displaying user information in card format.
- Worked with JavaScript arrays and objects to manage user data.
- Used loops to display multiple user cards dynamically.
- Experimented with adding and updating content on the webpage.

### 4. Basic CRUD Operations
CRUD stands for Create, Read, Update, and Delete.

- **Create:** Add a new user.
- **Read:** Display user information on the page.
- **Update:** Practice modifying existing user data.
- **Delete:** Remove a user from the displayed list.

Is practice se mujhe samajhne mein help mili ki JavaScript data aur DOM elements ko connect karke interactive UI kaise banaya ja sakta hai.

### 5. CSS Styling and Animations
- Practiced dark-themed UI styling.
- Experimented with RGB colors and glowing white box shadows.
- Worked with CSS transitions and hover effects.
- Created a hacker-style glitch animation for the **CWK** heading using pseudo-elements and keyframes.

### 6. Git and GitHub
- Practiced managing my project using Git.
- Worked with commands such as `git add`, `git commit`, and `git push`.
- Uploaded my practice work to GitHub to maintain a record of my learning.
